What would the flow of the app be like

The flow is a single path of five steps, with branches where the learner’s answers decide what happens next.

Main flow
Welcome ─► Step 1: Diagnostic ─┬─► (correct + confident) ─► Challenge path ─┐
                               └─► (M1 or unsure) ─► Step 2: Mass lab ──────┤
                                                                            ▼
                               Step 3: Length lab ─► Graph analysis ─► Step 4: Amplitude ─► Step 5: Extension ─► Summary
Step by step

Welcome

New learner: Start. Returning learner: “Resume at Step 3?”
The time estimate (about 10 min) is shown up front.

Step 1: Diagnostic (about 1 min)

Task 1: “Which bob has the shorter period, 1 kg or 3 kg?”
Correct → confirm briefly and offer the Challenge path (skips the guided mass lab).
Wrong (M1) → feedback: “Many people expect that, so let’s test it.” → Step 2.

Step 2: Mass lab (about 2 min, guided)

Learner writes a hypothesis, runs 3 masses and times 10 swings each.
Results show equal periods → learner marks the hypothesis supported or not, and revises it.
Task 1 is re-asked in a new form to check the revision.

Step 3: Length lab (about 3 min)

Task 3: predict T for L = 4 m, then run it.
Predicts 4.0 s → right, move on.
Predicts 8 s (M2) → the result shows 4.0 s → prompt: “What does that say about T ∝ L?” → plot T² vs L.

Graph analysis

Task 4: learner picks which graph is a straight line and reads the slope (≈ 4π²/g).
Wrong graph → short prompt, then retry.

Step 4: Amplitude (about 2 min)

Learner runs 5° and 60° and compares. Task 5: explain the difference.
The AI evaluator returns correct, partial or other, with feedback.

Step 5: Olympiad extension (about 2 min)

“A clock runs slow: what do you change, and by how much?”
Reached via the Challenge path or after completing Steps 2–4.

Summary

Shows which outcomes were met and which misconceptions came up and got resolved, then Done or Save for later.
Cross-cutting behaviours (apply at any step)
Failed experiment: if two variables change between trials, the confound is flagged, a guiding question appears, and a locked-variable re-run is offered.
Hints: 3 hint requests on one task → a simpler worked example.
Two correct in a row: unlocks the harder large-amplitude variant.
Save and pause: state is written to localStorage after every action, so the learner can stop at any screen and resume exactly there.
AI failure: falls back to rule-based feedback, with a visible “sample feedback” label.
The two scenarios the viva will ask you to walk through
Correct path: Welcome → Diagnostic ✓ → Challenge path → Length lab → Graph → Amplitude → Extension → Summary.
Misconception path: Welcome → Diagnostic ✗ (M1) → Mass lab → hypothesis revised → Length lab (M2 slip, then T² graph fix) → … → Summary.
